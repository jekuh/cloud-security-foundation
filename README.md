# cloud-security-foundation

Multi-cloud (AWS / Azure / GCP) **Cloud Security Foundation** repo built with Infrastructure as Code + CI/CD guardrails.
Each cloud is **fully independent** (own environment, modules, Makefile, pipelines, and bootstrap).

## Layout
- `aws/`   — AWS foundation (implemented)
- `azure/` — Azure foundation (scaffold)
- `gcp/`   — GCP foundation (scaffold)
- `docs/`  — cross-cloud docs

## Quick start
Choose a cloud folder and follow its README:
- `aws/README.md`
- `azure/README.md`
- `gcp/README.md`
